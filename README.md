Добавлена система VehicleEnterExit, позволяющая садиться в автомобиль и выходить из него по клавише E. 
При этом переключаются контроллеры управления и камеры. 
Расстояние для взаимодействия с машиной задается через Interact Distance в VehicleEnterExit на корневом объекте Car.

Добавлена возможность переключения внешнего вида автомобиля из заранее подготовленных вариантов. 
Для этого необходимо находясь рядом с машиной нажать F. 
Для внесения дополнительных вариантов необходимо добавить их в Visual Variants в корне самой машины, 
а также в Car Appearance Switcher.
